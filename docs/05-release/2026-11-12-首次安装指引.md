## 为什么需要这份指引

当前构建**未做代码签名**（D6）。操作系统会把安装包当成「未知发布者」，首次安装会弹拦截提示。这是预期行为，不是安装包损坏。拿到证书后只需在 CI Secrets 填 `WIN_CSC_FILE` / `WIN_CSC_KEY_PASSWORD` / `CSC_LINK` / `CSC_KEY_PASSWORD`，`electron-builder.yml` 里取消签名注释，不再需要本指引。

## Windows

1. 下载 `sshk-tools-<版本>-x64.exe`（NSIS 安装包）。
2. 若出现 **SmartScreen「Windows 已保护你的电脑」**：
   - 点「更多信息」→「仍要运行」；
   - 或右键安装包 → 属性 → 勾选「解除锁定」→ 确定，再双击。
3. 安装向导不是一键安装（`oneClick: false`），可以**自己选择安装目录**：
   - 在「选择安装位置」页点「浏览」选目录；
   - 默认安装到当前用户目录，`perMachine: false`，**不需要管理员权限**。
4. 建议管理员在内网分发时把安装包加入信任列表 / 组策略，避免每人都要点一次。

> 校验：Release 附件附带 sha512，可在 PowerShell 里 `Get-FileHash .\sshk-tools-*.exe -Algorithm SHA512` 比对。

## macOS

1. 下载 `.dmg`，双击打开，把 `sshk-tools` 拖进「应用程序」（**dmg 天然支持自行选择放置位置**）。
2. 首次打开若提示「无法打开，因为来自身份不明的开发者」：
   - **推荐**：在 Finder 里右键 App → 「打开」→ 再点「打开」（系统会记住例外）；
   - 或终端执行：`xattr -dr com.apple.quarantine /Applications/sshk-tools.app`。
3. 也可下载 `.zip` 解压后放到任意目录。

> 当前未做公证（notarization），**不提供任何绕过系统合规校验的方案**；拿到 Apple Developer ID 后启用签名 + 公证即可消除提示。

## Linux / 国产 OS

| 格式 | 安装 |
|---|---|
| `.deb`（统信 UOS / deepin / 麒麟系） | `sudo dpkg -i sshk-tools-*.deb`，缺依赖时 `sudo apt -f install` |
| `.rpm`（openEuler / 麒麟系） | `sudo rpm -i sshk-tools-*.rpm` 或 `sudo dnf install ./sshk-tools-*.rpm` |
| `.AppImage` | `chmod +x sshk-tools-*.AppImage && ./sshk-tools-*.AppImage`；**可放任意目录**，最灵活 |

deb/rpm 的安装位置由系统包管理器决定；需要自定义目录时请用 AppImage。

## 自动更新

- 客户端启动后由 `electron-updater` 检查 GitHub Releases 的 `latest.yml`，后台下载更新，提示「重启安装」（用户可延后）。
- 若公司内网访问不了 GitHub Releases，需要内网镜像或手动分发（见发布流程文档第九节「GitHub 可达性」）。

## 卸载

- 默认 `deleteAppDataOnUninstall: false`：**卸载会保留**模板、片段、邮件、海报、配置等用户数据。
- 如需彻底清理，手动删除应用数据目录（应用内「数据目录」按钮可打开）。
