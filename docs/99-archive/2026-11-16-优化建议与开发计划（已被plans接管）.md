| H3 | **全局错误边界 + 日志落盘**：应用级 Vue errorHandler + 主进程 unhandledRejection 捕获，日志写 userData 便于用户报障；当前用户报障只能靠"主进程终端输出" | 验证清单多处"把编号+截图+主进程终端输出发回" | P1 |
| H4 | **computed 副作用根治**：加载/请求逻辑统一 watch（immediate）+ 按 id 记 loading/failed，失败不自动重试。项目记忆踩坑 #3 已列，但 .vue 门禁查不出这类逻辑问题 | 项目记忆踩坑 #3 | P1 |
| H5 | **备份还原真实冒烟纳入门禁**：`导出→清空→导入还原` 端到端脚本化，含 D18 密钥加密迁移；M3 验收标准写了但无执行记录 | 选型稿 M3 验收 / 数据契约 §4 | P1 |
