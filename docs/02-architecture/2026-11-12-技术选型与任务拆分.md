#### 2.3.1 D18 已定：环境变量开关 + 加密密钥迁移

用户决策：**加一个系统环境变量，检测到就 100% 导出/导入还原，否则维持推荐（密钥不进包）**。

| 环境变量 | 值 | 行为 |
|---|---|---|
| `SSHK_TOOLS_ALLOW_SECRET_MIGRATION` | 未设置 / 其他值（默认） | 密钥**不进包**；导入完成页引导重填 N 个密钥 |
| `SSHK_TOOLS_ALLOW_SECRET_MIGRATION` | `1` / `true` | 导出包包含加密后的密钥；导入时可 100% 还原 |

**但环境变量只是「功能开关」，不是安全边界** —— 环境变量谁都能设，且 `safeStorage` 的密文与机器/系统账号绑定，换机本就解不开。所以 100% 还原必须走**口令派生密钥重新加密**：

```
导出（检测到开关）
  ① 界面二次确认 + 醒目提示「将导出模型密钥，请妥善保管 zip」
  ② 用户输入迁移口令（不写环境变量、不落盘、不进日志）
  ③ PBKDF2/Argon2id(口令, 随机 salt) → 派生密钥 → AES-256-GCM 加密 secrets
  ④ 包内 secrets.enc + manifest 记 secrets:"encrypted" / kdf / salt / nonce / iterations
导入（同样需检测到开关）
  ⑤ 显示「还原密钥」入口 → 输入同一口令 → 解密 → 用本机 safeStorage 重新加密落盘
  ⑥ 口令错误/缺失 → 跳过密钥，其余数据照常还原，明确提示
```

| 做法 | 评价 |
|---|---|
| 环境变量 + 口令加密（推荐/采纳） | 100% 还原且密钥不落明文；口令只在使用者脑子里 |
| 环境变量 + 明文密钥 | ❌ 不采纳：zip 一旦外发即泄露，且环境变量不构成授权 |
| 把口令也放环境变量 | ❌ 不采纳：会进 shell history / 进程列表 / CI 日志 |

设置方式（**由你在本机执行，我只给命令，不代跑**）：Windows `setx SSHK_TOOLS_ALLOW_SECRET_MIGRATION 1`；macOS / 国产 OS 在 `~/.zshrc` 或 systemd 用户环境里 `export SSHK_TOOLS_ALLOW_SECRET_MIGRATION=1`。两端都要开启：导出端开才能产出加密密钥，导入端开才会显示还原入口。

> 至此「100% 一模一样」只剩一个例外：**操作系统级授权**（右键菜单注册、开机自启、托盘权限）需在 B 机重新点一次，导入完成页提供「立即重新注册」按钮。

### 2.5 产物目录自定义与迁移（第三轮需求 5，新增）

> 需求原话：产物路径最好能通过应用自定义设置；使用中改目录时，把旧目录数据同步到新目录，成功后删除旧目录数据。

**配置项**：`app.outputDir`（应用配置 → 存储）。`null` = 默认 `app.getPath('userData')/sshk-data`。

**范围界定（待你确认 D21）**：推荐**只搬产物与资源**（`outputs/` + `assets/`），`settings` / `secrets` / NeDB `db/` 仍留 `userData`（safeStorage 与机器绑定、路径稳定更安全）。若你要连 `db/` 一起搬，方案同样适用，只是迁移清单多一项。

```
<outputDir>/
├── outputs/edm/<mailId>/…        # 覆盖式产物（需求 17）
├── outputs/poster/<pstId>/…
├── assets/                        # 模板本地 css/图片、上传的原始数据源
└── .storage-manifest.json         # 目录版本、文件清单 + checksum、迁移历史
```

**迁移流程（6 步，写成 `packages/storage`）**

| 步 | 动作 | 失败处理 |
|---|---|---|
| ① 预检 | 新目录存在/可写/剩余空间 ≥ 旧目录占用×1.2；不是旧目录的子目录；不与系统目录冲突；网络盘给出性能与文件锁提示 | 直接拒绝并说明原因 |
| ② 停写 | 暂停 NeDB 写队列与所有生成任务，等待在途任务结束 | 超时则中止，不破坏在途任务 |
| ③ 复制 | 复制到 `<newDir>/.migrating/` 临时子目录（**不直接覆盖**），逐文件记录 checksum | 清理临时目录，配置不变 |
| ④ 校验 | 文件数、总字节、抽样 hash、产物可打开、`.storage-manifest.json` 可解析 | 同上 |
| ⑤ 原子切换 | 写 `app.outputDir` + 更新所有路径映射（单事务/pointer），重开写队列；StatusBar 显示新路径 | 回退配置、清空新目录临时数据 |
| ⑥ 清理旧目录 | 见下方红线 | 删除失败**不回滚**已成功的迁移，只记待清理清单 |

**清理旧目录的红线（非常重要）**

- **绝不递归删除用户目录本身**。用户可能把产物目录设在桌面/文档/下载/某个共享盘根目录 —— 只删应用自己创建并**已登记在迁移清单里的具体文件**，以及应用自有的 `outputs/`、`assets/` 空目录；该目录下任何其他文件一律不动。
- 不做 `rm -rf` 式递归；按清单逐个删除，逐项记录结果。
- **二次确认**：弹窗明确列出将删除的路径与文件数、占用空间，用户确认后才执行；可勾选「暂不删除」。
- **延迟删除**：默认标记为「待清理」，下次启动复核新目录完好后再删；也可立即删。
- 迁移前把「旧目录清单 + checksum」存一份到新目录，供追溯。
- 删除失败、文件被占用、权限不足 → 只记录，不阻断迁移成功。

**联动**

| 联动项 | 处理 |
|---|---|
| 需求 6 导入导出 | zip 内一律相对路径；导入到 B 机重映射到 B 机 `outputDir`，**不带 A 机绝对路径** |
| 需求 17 覆盖式产物 | 切换后所有覆盖写入新根，固定相对路径不变 |
| D15 分享服务 | 只读白名单路由改指向新根 |
| 状态展示 | StatusBar 与「应用配置→存储」显示当前目录、占用空间、迁移历史 |

### T9 · 依赖版本 — **D20 已定：字面量 `latest`**（推翻 v0.2 的探测锁定方案）

用户明确：package.json 里**直接写** `"dayjs": "latest"`，所有包一样。采纳。

| 项 | 做法 |
|---|---|
| 版本字面量 | 所有依赖统一 `"latest"`（按用户要求） |
| **可复现底线** | **必须提交 `pnpm-lock.yaml`**；CI 用 `--frozen-lockfile`。`latest` 只是 specifier，真正装到什么版本由 lockfile 固定 |
| 刷新 | `pnpm up --latest` 刷新 lockfile → **单独 commit** → CI 门禁（typecheck/lint/test/build）全绿才合 |
| 巡检 | `scripts/check-latest.mjs` 只读对比 lockfile 解析版本与 registry dist-tag，输出「落后清单」，不自动改 |
| 大版本 | 单独 commit + 单独验证，不与功能开发混 |
| 重点回归包 | Electron / electron-builder / Vue / Element Plus / UnoCSS / Nunjucks / `@zumer/snapdom` / `@seald-io/nedb` / xlsx 解析库 / **dayjs**（T10 时间全靠它） |
| M0 待验证 | 由你执行 `pnpm install` 后验证 `--frozen-lockfile` 对 `latest` specifier 的行为；若 pnpm 拒绝，再定折中（此步我不代跑） |

⚠️ **风险**：没有 lockfile 时，`"latest"` 会让「同一份代码不同时间装出不同应用」，CI 与本机可能不一致。前车之鉴：juice-email-cli 的 `inquirer ^13.4.3 → ^14.0.2` 直接打挂发布命令。所以 **lockfile 是底线，不能省**；升级必须过门禁。

### T10 · 时间规范 — **第三轮需求 4：一律北京时间，不用 UTC**

> 推翻数据契约 v0.1「存储用 UTC，展示转本地」的写法。

| 项 | 约定 |
|---|---|
| 时区 | **Asia/Shanghai（UTC+8）**，无特殊情况不得使用 UTC |
| 存储格式 | ISO 8601 **带 `+08:00` 偏移**，如 `2026-11-12T21:08:28+08:00`；便于排序与解析 |
| 工具 | 统一 `packages/shared/time.ts`（dayjs + timezone 插件），提供 `now() / format() / parse() / toFileName()` |
| **禁令** | 禁止直接 `new Date().toISOString()`（输出 UTC）、禁止裸 `Date.now()` 直接入库（epoch 无时区语义）；ESLint 加规则拦截 |
| 覆盖范围 | `createdAt/updatedAt/lastGeneratedAt`、`exportedAt`、changelog 日期、导出 zip 文件名、目录迁移记录、分享 token 有效期、日志时间戳、列表展示 |
| 外部数据 | 邮件平台导出 csv 里若带 UTC 时间 → **入口处转北京时间再入库** |
| 系统值 | `fs.stat` 的 mtime/ctime 是 epoch，展示层统一转北京时间 |

```
① 数据源上传（可多文件）
   图片 / excel(xlsx) / csv / json
   └─ 【下载数据模板】csv / xlsx / json 空模板（表头 + 示例行 + 填写说明 sheet）
② 邮件 HTML（二选一）
   ├─ 选择：从 edm-studio 已生成产物列表按 mailId 选（走 repository 产物注册表）
   └─ 上传：外部 .html 文件
③ 点击生成
   → 统一归一为 LinkStat[] → 只读原 html → 覆盖生成 badged.html → snapdom → 覆盖生成 poster.png
```

| 上传格式 | 解析 | 是否需人工校对 |
|---|---|---|
| csv | 表头映射 `url / clicks / total_clicks` | 否（表头不符时给映射界面） |
| excel(xlsx) | 同表头 + 可选「填写说明」sheet | 否 |
| json | `[{ url, clicks, totalClicks }]` | 否 |
| **图片**（统计截图） | OCR（已有 PaddleOCR 环境）→ 转同一结构 | **是**，必须经人工校对页（数字识别易错） |
| 无结构化数据 | 手动映射表 / 未匹配项配对编辑器 | 是 |

四种来源统一归一为 `LinkStat[] { url, normalizedUrl, clicks, totalClicks, sourceFile }` → 后续 URL 归一、属性门控、一对多打标、badge 注入**只写一次**（需求 15）。
**只有含指定属性**（`tools.badge-studio.badgeAttr`，默认 `data-edm-badge`）的 `<a>` 才追加角标；没属性即使 URL 命中也不打标。一个链接命中多个标签 → 全部打同一个 `clicks`（D9）。

**海报列表**（需求 18）：空态提示去生成；新增 / 编辑 / 删除 / 复制海报 / 复制代码 / 导出（海报+代码）/ 重新生成 / 分享访问链接（html）/ 工具配置页。按钮、批量、表格布局全部复用 `ui-kit`。

## 7. 风险与前置条件（v0.4）

| 风险 | 影响 | 动作 |
|---|---|---|
| **`"latest"` + 无 lockfile** | 同一份代码不同时间装出不同应用；CI 与本机不一致 | **lockfile 必须提交** + CI `--frozen-lockfile` + 大版本单独提交（inquirer 前车之鉴） |
| **UTC 混入** | 时间错 8 小时，导出包/changelog/日志对不上 | ESLint 禁 `toISOString`，统一 `time.ts`，外部 UTC 数据入口转换 |
| **目录迁移误删** | 用户把产物目录设在桌面/文档时可能删到别的文件 | 只删清单内应用自有文件、不递归删目录、二次确认、延迟删除、失败不回滚 |
| 环境变量 ≠ 安全边界 | 误以为设了变量就能明文导出 | 密钥必须口令派生加密；明文方案明确不采纳 |
| 局域网分享 | 端口/防火墙/误绑公网 | 绑内网网卡、白名单路由、token + 有效期、一键停止 |
| 外链图片 CORS（Q8） | snapdom 截图空白 | 主进程代理下载转 dataURL + 等 `fonts.ready` + 降级 capturePage |
| 超长海报 canvas 上限 | 截断/缩放 | v3 分段窗口 + 检查 `warnings` |
| `fromString` 内联事件 | XSS | DOMPurify 消毒 / 受控 iframe |
| NeDB append-only 膨胀 | 数据文件变大 | `compactDatafileAsync` + `corruptAlertThreshold` |
| 无代码签名（D6） | 系统拦截安装 | 《首次安装指引》+ 签名开关 + sha512 校验 |
| 导入失败毁数据 | 不可逆 | 导入前快照 + 失败回滚 + 原子替换 |
| 右键菜单跨三平台 | 新机导入后不生效 | 导入完成页「立即重新注册」 |
