# 安全与密钥体系（A-T2，2026-11-16 落档 · 单一权威）

- 本文取代散落各处的安全说明（上传能力规划 N10、设置页访问密钥说明等改为引用本文）。
- 红线原则：**不联网 / 不登录 / 不加密用户业务文件 / 仅本机可见性门禁**——所有口令与密钥机制都只做「本机能力解锁」，不参与任何远程认证。

## 一、五套口令 / 密钥对照表（以代码为准）

| # | 名称 | 作用 | 存储位置 | 失效影响 | 重置方式 |
|---|---|---|---|---|---|
| 1 | **开发者工具 / 开发者模式访问密钥** | 打包版开启「开发者模式」「打开开发者工具」的同一口令（双闸：UI 弹框 + main `configSet` 二次校验 `devModeAuthorized`，防绕过 UI） | `settings.json` `app.devtoolsKeyHash`（**只存 sha256 摘要**，明文不落盘） | 开发者模式开关回弹，开发者功能不可用 | 设置页重新设置访问密钥（`accessKey:set` → `setAccessKey`，写新摘要） |
| 2 | **LLM Provider API Key** | 模型网关调用鉴权 | `userData/secrets.bin`（safeStorage 加密，键 = providerId）**永不下发渲染层** | 该 Provider 调用 401；模型管理回退预设模型 | 模型管理重新填写（明文入口 → safeStorage → 摘要回显） |
| 3 | **上传 profile 口令 / 密钥** | FTP/SFTP/云厂商认证 | `secrets.bin`（safeStorage，键 = profileId）；**测试连接用表单临时值，不落盘** | 该 profile 上传/测试失败 | 上传配置工具重新保存 profile |
| 4 | **备份迁移口令（可选）** | 备份 zip 中 Provider 密钥的加密迁移（`migrationPassphrase`，仅密钥加密迁移开启时生效） | 不落盘——仅导出/导入时用户输入 | 导入时无法解密 Provider 密钥，需重填 | 无持久状态，重新输入即可 |
| 5 | **工具访问 grant** | 工具可见性门禁：设为「需访问密钥」的工具在密钥未配置时从列表隐藏 | manifest `requiredGrant`，运行时被 `tools.<id>.requiredGrant` 覆盖（settings.json） | 该工具隐藏（配置密钥后重新出现） | 工具与权限页改 grant 或配置访问密钥 |

> secrets.bin 细节：safeStorage 异步解密预载内存缓存；`shouldReEncrypt` 时自动用当前 OS 密钥重加密落盘；safeStorage 不可用**不静默丢密钥**——日志留警告，密钥保留在磁盘待环境恢复。

## 二、进程边界三条红线（Electron）

| 项 | 配置 | 说明 |
|---|---|---|
| `nodeIntegration` | **false** | 渲染层无 Node 能力，一切系统能力经 IPC |
| `contextIsolation` | **true** | 渲染层只见 preload 暴露的 `window.api` 白名单 |
| `sandbox` | preload 白名单暴露 | `preload/index.ts` 是唯一 IPC 暴露面；新增能力一律走 `@sshk/ui-kit` 的 `callHostApi()`（N8 纪律），不裸调 |

- CSP（`apps/desktop/index.html`）：`script-src 'self' blob:`（运行时工具包 Blob 模块）；`img-src`/`connect-src` `'self' https:`（外链图片显示与截图 fetch）。
- 工具包（.sshktool）导入时过契约校验（manifest/IPC 白名单），运行时按 `package.ipcAllowlist` 限制可调用的宿主通道。

## 三、密钥流转图

```
明文入口（设置页 / 工具表单，仅内存）
  → safeStorage.encryptString → secrets.bin（磁盘密文）
  → 回显只给「已配置/未配置」布尔或摘要，明文不回传渲染层
  → main 侧按需解密使用（llm 网关 / upload Provider）
访问密钥：明文入口 → sha256 摘要 → settings.json devtoolsKeyHash（不可逆）
```

## 四、env 变量安全清单

- 权威文件：仓库根 `.env.example`（与本文双向对照；新增 env 必须同步两处）。
- 诊断报告（N1）只列**变量名 + 是否已设置**，绝不打印值；日志脱敏红线同 §六。
- 当前状态（A-T1）：用户暂未实际设置 env，`.env.example` 有效性待设置后对照。

## 六、日志与诊断报告的脱敏红线（与 plans/04 呼应）

日志（H3）与诊断 zip（N1）**绝不写入**：apiKey、上传密码、访问密钥、口令；safeStorage 相关只记布尔与 profileId；env 只列变量名。任何新埋点落盘前先过此清单。
