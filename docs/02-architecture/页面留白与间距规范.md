# 页面留白与间距规范（全项目强制）

> 立项：2026-11-19 用户反馈「内容区直接靠边了，需要留有一定间距。本项目所有页面实现都该如此」。
> 结论：作为本项目**长期规范**执行——所有页面根容器必须有留白、页内各区块/板块之间必须有间距，禁止内容贴边。

## 一、设计 token（唯一来源：apps/desktop/src/renderer/styles/theme.css 的 :root）

| token | 值 | 用途 |
|---|---|---|
| `--sshk-page-padding` | `20px` | 页面内容区四周留白（页面根容器 padding） |
| `--sshk-gap-sm` | `8px` | 紧凑间距：工具栏内按钮间、表格/分页与工具栏之间 |
| `--sshk-gap-md` | `12px` | 常规间距：卡片之间、常规区块之间 |
| `--sshk-gap-lg` | `16px` | 宽松间距：大区块、桌面卡片网格 |

调整留白**只改 token**，全项目自动生效，禁止在页面里写死的具体 px 覆盖。

## 二、强制规则

1. **页面根容器必须有 `padding: var(--sshk-page-padding)`**（上下左右 20px）。
   - 使用 `ToolPageLayout` 的页面：由全局 `.tool-page-body { padding: var(--sshk-page-padding) }` 统一提供，页面自身**不要再写** padding（避免双重）。
   - 不使用 `ToolPageLayout`、自管根容器的页面（如 `ContentsPage` / `ContentEditorPage`）：根容器**必须显式** `padding: var(--sshk-page-padding); box-sizing: border-box`。
   - 桌面落地页 `.desktop` 的 `28px 32px` 是既定特例（大网格），保留。
   - 弹框内部内容（如 VerifyGuidePage 在 el-dialog 内）由弹框自身内边距提供，不套用本规范，避免双重留白。

2. **页内区块之间必须有间距**：
   - 采用 flex/grid 布局时用 `gap`；纵向排列的区块（工具栏 → 表格 → 分页）用 `gap: var(--sshk-gap-sm)`。
   - 卡片网格用 `gap: var(--sshk-gap-md)` 或 `--sshk-gap-lg`。
   - 禁止相邻区块 `gap`/`margin` 为 0 导致视觉粘连。

3. **弹框 / 浮层里的表单区同样遵守**：标题栏、正文、footer 三段之间留白，正文不得贴弹框边。

## 三、落地清单（2026-11-19）

| 文件 | 改动 |
|---|---|
| `theme.css` | 新增 4 个 token；`.tool-page-body` padding 改用 token |
| `tools/file-manager/.../ContentsPage.vue` | 根容器补 padding + gap（此前贴边，用户反馈点） |
| `tools/file-manager/.../ContentEditorPage.vue` | 整页编辑器壳根容器补 padding（同上） |

其余使用 `ToolPageLayout` 的页面已由全局 `.tool-page-body` 提供 20px 留白，符合规范，无需改动。

## 四、自检口径

新增/改动任何页面时逐条自查：
- [ ] 根容器留白 20px（ToolPageLayout 页面除外，由全局提供）？
- [ ] 页内相邻区块有 gap（≥8px）？
- [ ] 没有写死的具体 px 覆盖 token？
- [ ] 表格/分页不贴边、不贴弹框底？
