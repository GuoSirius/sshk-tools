## 一、需求与选型

> 开发环境 Electron 支持热更新，**无论主进程还是渲染进程，只要改动就要更新或重启**。

| 方案 | 主进程 | preload | 渲染进程 | 优势 | 不足 | 结论 |
|---|---|---|---|---|---|---|
| **electron-vite**（推荐） | 改动自动重启 | 改动自动重载渲染进程 | Vite HMR | 一套配置覆盖三端；与已定 `electron-builder` 共存；可分别指定 ESM/CJS 产物 | 多一个 devDependency | ✅ |
| Vite + electronmon 手搓 | 监听重启 | 要自己写 reload | Vite HMR | 灵活 | 三套配置、preload 最容易漏，改动后经常「不生效」 | ❌ |
| Electron Forge + Vite 插件 | 有 HMR | 有 | 有 | 官方一体化 | 与 D4 已定的 electron-builder 发布链路冲突，两套构建规范 | ❌ |
| webpack + electron HMR | 有 | 自己配 | 有 | 老项目可用 | 配置繁琐、对 Vue SFC + UnoCSS 不友好 | ❌ |

**结论**：`electron-vite dev` 一条命令覆盖三端，构建产物 `out/main`、`out/preload`、`out/renderer` 正好对接 `electron-builder`。

## 二、落地配置

`apps/desktop/electron.vite.config.ts` 三块：

| 块 | 源码 | 产物 | 格式 | 说明 |
|---|---|---|---|---|
| `main` | `src/main/index.ts` | `out/main/index.mjs` | **ESM** | 主进程，Electron 28+ 支持 |
| `preload` | `src/preload/index.ts` | `out/preload/index.cjs` | **CJS** | `sandbox: true` 硬性要求，产物固定 `.cjs` |
| `renderer` | `index.html` + `src/renderer/**` | `out/renderer/**` | ESM | Vite + Vue 插件 + UnoCSS |

`@sshk/shared` 通过 `resolve.alias` 指向 `packages/shared/src/index.ts`，改动共享包会按依赖图触发对应端热更。

## 三、改动行为对照

| 改动位置 | 行为 |
|---|---|
| `src/main/**` | 主进程重新编译并**自动重启 Electron**（窗口重建） |
| `src/preload/**` | 重新编译 preload，**自动重载渲染进程**，不重启主进程 |
| `src/renderer/**` | Vite HMR，组件局部更新、尽量保留状态 |
| `index.html` / `uno.config.ts` / `electron.vite.config.ts` | 需重启 dev 进程（配置变更） |
| `packages/shared/**` | 由依赖图触发主进程/渲染进程相应热更 |
| `apps/desktop/build/**`（图标） | 重新构建后生效 |

## 四、命令（安装与启动由你执行，AI 不代跑）

```bash
pnpm install                          # 首次，含 electron 二进制（已配 npmmirror 镜像）
pnpm --filter @sshk/desktop dev       # 启动开发态：三端热更新
pnpm --filter @sshk/desktop build     # 产出 out/ 给 electron-builder 打包
pnpm verify                           # 结构 / 分层 / latest / typecheck / lint / test
```

根 `.npmrc` 已配 `registry` 与 `electron_mirror` 为国内镜像，避免 Electron 二进制下载卡住。**注意**：npmmirror 没有 audit 端点，查漏洞要显式 `pnpm audit --registry=https://registry.npmjs.org`。

## 五、不变的红线

- `nodeIntegration: false` + `contextIsolation: true` + `sandbox: true`，热更新不改变进程边界。
- preload **只做** `contextBridge.exposeInMainWorld` 白名单，不承载业务逻辑。
- 密钥永不下发渲染进程；模型 apiKey 仍由主进程 `safeStorage` 持有。
- `index.html` 已设 CSP；`img-src` 允许 `data:` 与 https（EDM 外链图片需要）。
- 时间一律北京时间；ESM 里取路径用 `import.meta.url` + `fileURLToPath`，不用 `__dirname`。
