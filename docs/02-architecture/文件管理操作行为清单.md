# 文件管理 · 操作行为清单（供逐项核对）

> 生成时间：2026-11-18。权威代码：`tools/upload-manager/src/renderer/pages/FileExplorerPage.vue` + `apps/desktop/src/main/fs.ts`。
> 用途：用户逐项核对「按钮 → 条件 → 动作 → 反馈」是否符合预期；不符直接按编号反馈。
> 通用规则：**删除/覆盖/重新生成类危险操作一律二次确认**；写操作按通道实时显隐（仅浏览厂商全部置灰）；`hasWritable` = 通道可写（阿里云 OSS / AWS S3 / SFTP / 本地目录可写，其余云厂商仅浏览）。

## 6. 传输队列悬浮面板（plans/10，替代旧底部抽屉）

| # | 控件 | 条件 | 动作 |
|---|------|------|------|
| Q0 | 面板形态 | 恒显（首次收起） | 悬浮于列表上（无遮罩、不锁页面）；`useDraggable` 拖拽（手柄 ⠿），收起态摘要条同样可拖；位置/展开态/分栏/过滤记忆（`sshk.fs.transferPanel`）；「回到默认位置」复位；resize clamp 回可视区 |
| Q1 | 全部开始 ▶ / 全部暂停 ⏸ / 全部停止 ⏹ | 有未完结任务 | startAll / pauseAll / stopAll（停止二次确认，禁遮罩禁 ESC） |
| Q2 | 失败重试 ↻ | 有 failed/canceled | 批量重试 |
| Q3 | 清理已完结 🗑 | 恒显 | 二次确认后移除 success/failed/canceled/conflict 任务 |
| Q4 | 分栏 | 恒显 | 全部 / 上传 / 下载 / 其它；计数「完成数/总数」；名称搜索过滤 |
| Q5 | 单条：开始/暂停/继续/停止/重试/覆盖/移除 | 按状态显隐 | queued→开始/停止；running→暂停/停止；paused→继续/停止（resumable 标「断点续传」+ 片数）；conflict→覆盖/停止；failed/canceled→重试/移除；success→移除；停止/移除二次确认 |
| Q6 | 遗留分片 | orphans>0 | 面板/传输设置显示服务端遗留 uploadId 数；手动清理（二次确认，逐个 abort） |

**引擎行为（plans/10）**
- 状态机：`queued → running → paused → …`；暂停为协作式——running 置「暂停中…」，在片/块/目录项边界停下，保留进度与检查点
- 上传分片：>阈值（默认 50MB，可配）且驱动支持（OSS/S3）走 multipart；检查点 `userData/fs-transfer/checkpoints/<id>.json` 每片原子写；续传先 `listParts` 与本地比对只补缺片；源文件 path/size/mtime 变更即废弃检查点并 abort 旧 uploadId 重开；失败保留检查点，只有「停止」才 abort+删检查点；10000 片上限自动上调单片大小；同时开片任务数上限 2
- 下载分片：>阈值且驱动具备 Range（local/SFTP/OSS/S3；FTP 回落单流）按段下载到 `<dest>.sshkpart` + 区间元数据，完成校验后原子改名；续传先比源指纹（本地/远程 mtime+size，云 ETag+size），变更即删临时文件重下
- 持久化：只持久化未完结 upload/download（`userData/fs-transfer/queue.json`，300ms 防抖 + 退出 flush）；重启恢复一律 paused、不自动续跑；copy/cross/delete 预留不写盘
- 单一控制通道 `fs:transfer:control`（start/pause/resume/stop/retry/remove/startAll/pauseAll/stopAll/retryFailed/clearFinished）；旧 cancel/retry/clear 三通道已删
