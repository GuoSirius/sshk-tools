# 文件管理 · 操作行为清单（供逐项核对）

> 生成时间：2026-11-18。权威代码：`tools/upload-manager/src/renderer/pages/FileExplorerPage.vue` + `apps/desktop/src/main/fs.ts`。
> 用途：用户逐项核对「按钮 → 条件 → 动作 → 反馈」是否符合预期；不符直接按编号反馈。
> 通用规则：**删除/覆盖/重新生成类危险操作一律二次确认**；写操作按通道实时显隐（仅浏览厂商全部置灰）；`hasWritable` = 通道可写（阿里云 OSS / AWS S3 / SFTP / 本地目录可写，其余云厂商仅浏览）。

## 2. 工具栏

| # | 按钮 | 可用条件 | 动作 | 反馈 |
|---|------|----------|------|------|
| T1 | 上传▾（success 绿） | 已选通道 | 下拉三项：上传文件 / 上传文件夹（保留结构）/ 从 EDM 产物目录选择… | 系统弹框选完 → 展平入队；成功 toast「已加入传输队列：N 个文件」+ 自动开传输抽屉；展平/入队失败红 toast 原样报错；空结果黄 toast「没有可上传的文件」 |

| T5 | 复制（剪贴板，warning 黄） | 已选 ≥1 项 | 把所选加入剪贴板（复制语义；行内「复制」是弹框直落，二者分工） | 粘贴按钮变为「粘贴（N 项）」 |

| T7 | 移动（warning 黄） | 已选且可写 | 弹框选目标目录 → 移动 | mv 完成刷新；备注随移动自动迁移；失败如实报错 |
| T8 | 重命名 | 恰选 1 项且可写 | 弹框输入新名 | 成功刷新；重名报错 |
| T9 | 删除（danger 红） | 已选且可写 | 确认弹框（列出所选项）→ 目录递归删除入队（带进度）、文件直接删 | 确认后才执行；父目录无写权限时预检拒绝并明示原因 |
| T10 | 更多▾ 设置备注 | 已选且可写 | 弹框多选合并为一个备注（批量=同备注）；留空=清除 | 确认后生效，备注列即时更新 |
| T11 | 更多▾ 添加收藏 | 已选 ≥1 | 收藏所选（同通道同路径幂等） | 收藏夹抽屉可查 |
| T12 | 更多▾ 收藏夹… | 恒可点 | 打开收藏抽屉；每项可「前往」（跨通道直达）/「删除」 | 前往自动切通道+跳目录 |
| T13 | 更多▾ 复制路径 | 已选 ≥1 | 所选路径复制到剪贴板（多项换行拼接） | toast「路径已复制」 |
| T14 | 更多▾ 压缩为 zip… | **仅本地通道**且可写且已选 | prompt 输入 zip 名 → 递归收集文件压缩写回当前目录 | 成功 toast「已压缩 N 个文件 → 名（大小）」+刷新；超文件数/容量上限中止并报错（上限见 T21 可配）；非本地通道按钮置灰 |
| T15 | 更多▾ 解压到新目录 | 仅本地通道、恰选 1 个 .zip | 确认弹框 → 解到 zip 同级同名目录 | 成功 toast「已解压 N 个文件 → 目录」；防路径穿越，含非法条目整包中止 |
| T16 | 更多▾ 转换文本编码/换行符… | 恰选 1 个文本扩展文件（全通道） | 弹框选源编码（可自动检测）/目标编码/换行符 → 确认后**直接写回原文件** | 完成提示实际检测到的编码与变更结果；>20MB 拒绝；建议先下载备份 |

| T18 | 更多▾ 属性 | 恰选 1 项 | 弹框展示名称/路径/类型/大小/创建·修改时间/权限/用户组/备注（按通道如实有则显示）+ 编辑入口 | — |

| T21 | 更多▾ 列设置… | 恒可点 | 开关 备注/创建时间/权限/用户组列；通道无数据的列禁用；显隐记忆 | 即时生效 |

| T22b | 更多▾ 传输上限设置… | 恒可点 | 配置上传目录展平 / 下载目录递归展开共用的文件数上限（100~100000，默认 10000） | toast「传输文件数上限已更新」，跨重启记忆 |

## 3. 列表视图（行）

| # | 交互 | 条件 | 动作/反馈 |
|---|------|------|-----------|
| R1 | 单击行 | — | 选中该行（替换选择） |
| R2 | Ctrl+单击 | — | 加选/取消选 |
| R3 | Shift+单击 | — | 范围选择 |
| R4 | 复选框列 | — | 勾选=加选；表头复选框=全选/清空（半选态自动显示）；该列横向滚动时**固定在左** |
| R5 | 双击行 | — | 目录=进入；文件=智能打开：文本（≤256KB）进编辑器 / 图片预览 / 音视频播放（≤64MB）/ 其它引导下载 |
| R6 | 行外显按钮 | 按类型与通道实时显隐 | 下载(文件)→链接(文件)→粘贴(目录，剪贴板有内容才出)→复制→移动→重命名→删除→更多▾；配色语义：绿=下载/粘贴、蓝=链接/重命名、黄=复制/移动、红=删除；操作列横向滚动时**固定在右** |
| R7 | 行「链接」 | 文件 | 复制 baseUrl+路径外链；未配 baseUrl 黄 toast 引导去通道配置 |
| R8 | 动态列 | — | 备注(默认开)/创建时间/权限/用户组；通道无数据整列隐藏；**表头与数据行共用同一组列宽（subgrid），不再错位** |
| R9 | 行「更多▾」 | — | 信息组（属性/统计/设置备注/收藏/复制路径）+ 工具组（压缩/解压仅本地、转换仅文本）+ 权限组（编辑权限、安全分享仅本地） |
| R10 | 安全分享 | 本地通道文件/目录 | ShareHub 弹框生成有 TTL 可撤销链接+二维码；有效链接复用不重建 |
