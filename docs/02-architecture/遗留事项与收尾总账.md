| 原则 | 说明 |
|---|---|
| **验证优先于新增** | 当前 30+ 条 `⏳ 待验证` 是本阶段核心债务；新功能开发前先把已落代码实跑闭环 |
| **优先验 B 组** | 富文本全屏（E-V6）用户两次反馈未修好，先验它 |
| **逐条打勾留痕** | 验证按验证清单 A→B→C→D→E 顺序，不符即记编号+截图+主进程终端输出 |
| **门禁守住** | 每次改动仍走 husky `pnpm verify` + desktop build，conventional commit 推 main |
| **状态实时回写** | 推进时同步更新本账状态 + 对应专项文档，避免状态再次失真 |
