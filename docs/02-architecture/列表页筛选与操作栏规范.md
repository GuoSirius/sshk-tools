# 列表页筛选与操作栏规范

> 定版：2026-11-20（用户明确要求，作为本项目**所有列表页面**的通用开发规范）。
> 首次落地参照：`tools/file-manager/src/renderer/pages/ContentsPage.vue`、`tools/share-manager/src/renderer/pages/LogsPage.vue`。

## 1. 筛选栏：统一「label + 控件」形式

- 每个筛选控件前必须有一个文本 label（如 `搜索`、`时间`、`标签`、`分享状态`、`发布状态`），**明确告知用户在筛什么**，不允许只靠 placeholder 传达语义。
- label 统一样式：12px、次要文字色（`var(--el-text-color-secondary)`），与控件同排垂直居中，间距用 `--sshk-gap-sm`。
- 控件 placeholder 只写「全部 / 标题 / 描述」等短词即可，不重复 label 语义（禁止再出现「全部分享状态」「状态码：全部」这类把语义塞进首选项/placeholder 的写法）。

## 2. 控件宽度统一

| 控件类型 | 宽度 |
| --- | --- |
| 输入框 / 单选下拉 / 多选下拉（默认） | `180px` |
| 时间范围选择器 | `400px` |

- 同一页面内同类控件宽度必须一致；一行放不下时允许 flex-wrap 换行，不允许为凑行宽而压缩某个控件。
- 单个时间选择器（非范围）也按 180px。

## 3. 时间范围默认精确到时分秒

- **默认**：`type="datetimerange"` + `value-format="YYYY-MM-DD HH:mm:ss"`，配 `:default-time="[00:00:00, 23:59:59]"`，筛选比较用毫秒闭区间（`Date.parse` 后 `>=` start && `<=` end）。
- **例外**：业务语义本身就是按日的（如用量统计按自然日汇总、账单日切分），可退化为 `daterange` / 日粒度，需在代码注释说明例外原因。
- 禁止在筛选层把时间截断到日（`iso.slice(0, 10)` 比较）再交给数据库——用户看到的精度必须与实际过滤精度一致。

## 4. 操作栏：单独一行、居右

- 页面顶部区块顺序固定为：**筛选栏（上）→ 操作栏（下）→ 表格 → 分页**。
- 操作按钮（新建/导出/批量删除等）独占一行，`justify-content: flex-end` 居右，不得与筛选控件混排一行。
- 危险/批量操作与普通操作之间可用 `el-divider direction="vertical"` 分组。

## 5. 其它配套（沿用既有规范）

- 分页信息中文化：全局 zhCn locale 已注册，勿再手写「共 X 条」到分页（LogsPage 操作栏的「共 X 条」是服务端分页总数展示，属例外）。
- 页面根容器留白 `--sshk-page-padding`、区块间距 `--sshk-gap-sm`，见《页面留白与间距规范.md》。
- 危险操作（删除/清空）一律二次确认（ElMessageBox / ConfirmDialog，禁遮罩禁 ESC）。
