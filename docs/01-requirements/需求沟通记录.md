### 需求 7 展开（badge + 海报）

1. 生成好的邮件可能需**上传图片 / excel / csv / json**，内含**链接 + 对应点击次数**。
2. 在生成的 HTML 里找到对应**链接标签**，往标签**追加 badge 角标**标记数量。
3. 点「生成图片」把带 badge 的 HTML 生成**海报形式长图**。
4. **一个链接可对应多个标签**：仅含指定属性的标签在匹配链接后才追加；无特殊属性的标签即使 URL 命中也**不追加**。
5. 带 badge 的 HTML 与「右键 HTML」**互相独立**，都不能影响原邮件 HTML（两者后期都可能被多次使用）。

> 术语：右键 HTML = 可发送邮件 HTML（只读产物）；badge 版 HTML = 汇报展示用**独立副本**，可反复重生成。

## 四、数据源与输入组合（D10）

用户上传格式：**图片 / excel(xlsx) / csv / json** 四种 + **选择或上传**已生成的邮件 HTML → 点击生成 → badge 注入 → 海报。

- 主通道：平台导出 **csv / xlsx**（D10 定，不做 OCR 主力）；图片保留为兜底（OCR → 人工校对页）。
- 四种来源统一归一为 `LinkStat[]`，后续逻辑只写一次（见选型稿 §4.5 / 数据契约 §6 `DatasourceUpload`）。
