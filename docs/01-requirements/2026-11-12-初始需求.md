## 一、项目背景

AI 盛行，公司内部需要一个**本地工具集合**，用于开发、定制日常工具，供各部门与人员使用。工具需具备两类底层能力：

| 能力 | 要求 |
|---|---|
| 调用操作系统 | 文件、剪贴板、右键菜单、托盘、外部命令等本地能力 |
| 调用大模型 | 支持 **本地模型 / 云模型 / 自部署模型服务** 三类后端 |

### 需求 7 展开

1. 生成好的邮件，可能需要**上传图片 / excel / json**；这些文件里包含**链接 + 对应点击次数**。
2. 在生成的 HTML 里找到对应**链接标签**，往标签里**追加 badge 角标**，标记数量。
3. 用户点击「生成图片」，把带 badge 的 HTML 生成**海报形式的长图**。
4. **一个链接可能对应多个标签**：代码中会明确给出属性，**只有包含指定属性的标签**在匹配链接后才追加 badge；没有特殊属性的标签即使 URL 命中也**不追加**。
5. **带 badge 的 HTML 与之前的「右键 HTML」互相独立**，不能影响原有邮件 HTML —— 因为两者后期都可能被**多次使用**。

> 术语澄清：这里的「右键 HTML」指旧工具通过右键菜单生成/复制的那份**可发送的邮件 HTML**；badge 版是**汇报展示用的衍生副本**，不是要发出去的邮件。

## 四、术语表（后续文档统一口径）

| 词 | 含义 |
|---|---|
| 模板 Template / 模板版本 | 邮件的整体布局骨架 / 骨架的一份具体内容（v1、v2） |
| 片段 Fragment / 片段版本 | 可复用区块（header、产品卡片、footer、CTA）/ 该区块的一份具体内容 |
| 版本变种 | 同一模板或片段的不同版本，用于微调、A/B、节日换肤 |
| 邮件 Email | 一次生成实例 = 模板版本 + 若干片段版本 + 填充数据 |
| 测试数据 sampleData | 模板/片段自带的一份示例数据，用于一键预览 |
| 右键 HTML / 原始邮件 HTML | 可发送的邮件 HTML 产物，生成后只读 |
| badge 版 HTML | 汇报展示用的**独立副本**，可反复重生成 |
| 海报长图 | badge 版 HTML 截图得到的整页 PNG |
