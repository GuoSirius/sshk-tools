# 08 · 文件管理系统（上传配置工具 · X6）

> 来源：用户 2026-11-16。已配置 1 个远程（FTP）+ 4 个阿里云 OSS 通道，希望有一个真正的文件管理器：
> 参考 oss-browser（对象存储浏览）与 1panel（服务器文件管理）的实现，再加自有理解。
> **定位：进入上传配置工具默认展示「文件系统」页，「上传配置」退居第二菜单。**

## 一、目标与非目标

| 项 | 内容 |
|---|---|
| 目标 | 对已配置的 5 个通道（远程 FTP/SFTP + 云 OSS）做完整的远端文件浏览与管理：浏览、上传/下载、新建目录、重命名、复制/移动、删除、查看、编辑保存、批量操作、传输队列 |
| 非目标 | ① 不做跨通道互拷（一期）；② 不做回收站（对象存储无原生回收站，删除仅二次确认）；③ 不做 shell/终端（1panel 的终端属于服务器管理场景，与本工具无关）；④ 不做子用户/权限管理（oss-browser 场景，AK 权限本身已受控） |

## 二、能力矩阵（后端 × 操作，先立契约再动手）

| 操作 | FTP/SFTP（basic-ftp/ssh2） | 阿里云 OSS（ali-oss） | 说明 |
|---|---|---|---|
| 目录浏览（名称/大小/时间） | ✅ 原生 | ✅ listV2 + delimiter（目录=公共前缀，虚拟） | OSS 无真实目录层级 |
| 新建目录 | ✅ mkdir | ✅ 写 0 字节 marker 对象 `dir/` | |
| 删除文件 | ✅ | ✅ | |
| 删除目录（递归） | ✅ | ✅ 按前缀批量删（分批+进度） | 高危操作单独确认 |
| 重命名 | ✅ rename | ✅ copyObject + 删原对象 | OSS 语义为「复制+删」 |
| 复制 | ⚠️ 下载+重传（无服务端复制） | ✅ copyObject | FTP/SFTP 大文件复制较慢，队列化 |
| 移动 | ✅ rename | ✅ copy+delete（跨目录） | |
| 上传 / 下载 | ✅ 流式 | ✅ 流式 | 都走传输队列 |
| 读取内容（预览/编辑） | ✅ readFile/下载 | ✅ get | 有大小阈值（见 §六） |
| 权限/属性 | ⚠️ SFTP chmod/stat；FTP 仅 stat | ❌ 无（只有元数据） | 权限列仅 SFTP 有值 |
| 容量/数量统计 | ❌（逐步求和太慢） | ✅ getBucketInfo/逐步前缀统计 | 后端差异在 UI 上「有就显示」 |

> 契约落点：`@sshk/shared` 新增 `FsEntry` / `FsListQuery` / `FsOp` 类型 + IPC 通道白名单；main 侧 `upload-core` 新增 `fs-remote.ts`（FTP/SFTP 浏览驱动）与 `fs-cloud.ts`（OSS 驱动，复用已加载 SDK）。

## 三、界面设计（参考两者之长 + 自有理解）

### 3.1 整体布局（单页三段）

```
┌─ 通道切换条 ────────────────────────────────────────────┐
│ [通道下拉 ▾]（云/远程同列，图标区分类型） · 默认通道记忆  │
│   右侧：容量/对象数摘要（OSS）· 当前账号脱敏标识（LTAI…） │
├─ 路径区 ────────────────────────────────────────────────┤
│ ← → ↑ 刷新 │ 面包屑： bucket / a / b / c（可点击逐级跳） │
│   路径可编辑（回车直达，oss:// 前缀风格同 oss-browser）   │
│   右侧：搜索过滤框（当前目录前缀匹配）· 列表/网格切换     │
├─ 工具栏 ────────────────────────────────────────────────┤
│ 上传 ▾(文件/文件夹/拖拽提示) · 下载 · 新建文件夹 ·       │
│ 复制 · 粘贴 · 移动 · 重命名 · 删除 · 更多▾(刷新/统计)    │
│   （批量按钮在选中 ≥1 时点亮；粘贴在有剪贴板内容时点亮）  │
├─ 文件列表 ──────────────────────────────────────────────┤
│ □ 名称 | 类型/大小 | 修改时间 | （SFTP: 权限）| 操作列   │
│ 行操作：打开/预览 · 下载 · 复制 · 移动 · 重命名 · 删除   │
├─ 状态条 ────────────────────────────────────────────────┤
│ 共 N 项（M 目录 K 文件）· 已选 X · 传输队列角标（进行中） │
└─────────────────────────────────────────────────────────┘
```

- **oss-browser 借鉴**：面包屑 + 可编辑路径栏 + 类型列（目录/文件区分图标）+ 行内操作列直达
- **1panel 借鉴**：行尾「更多」抽屉（复制/移动/重命名/解压类高级操作收拢）+ 底部统计条 + 双视图切换
- **自有理解**：与 EDM 工具联动的「上传到此处」（右键把 EDM 产物直接传到当前目录）；剪贴板跨目录粘贴；空态引导（未选通道 → 跳配置页；目录为空 → 拖拽上传提示）

### 3.2 列表展示字段

| 字段 | 目录 | 文件 | 备注 |
|---|---|---|---|
| 名称 | 文件夹图标+蓝字 | 按扩展名图标 | 排序：目录恒在前，名称升降可切 |
| 类型/大小 | 「目录」 | 人类可读大小（B/KB/MB…） | 目录不显示大小（OSS 前缀无意义；FTP 可选「计算」如 1panel，二期） |
| 修改时间 | OSS marker 为创建时间；FTP 为 mtime | mtime | 相对时间 + 悬浮绝对时间 |
| 权限 | 仅 SFTP：0777 样式 | 同 | 其他后端隐藏该列 |
| 操作 | 打开 · 删除 | 预览 · 下载 · 复制 · 移动 · 重命名 · 删除 | 高频行内直达，长尾进「更多」 |

### 3.3 交互细节

- **多选**：checkbox + Shift 范围选 + Ctrl 点选；全选当前目录；选中后工具栏批量按钮点亮，底部显示「已选 X 项」
- **拖拽**：从资源管理器拖文件/文件夹进列表 → 上传到当前目录（含递归展平进度）；行内拖拽排序不做
- **搜索**：前端过滤（当前目录内）为主；「递归搜索」二期（OSS 用 listV2 无 delimiter 扫前缀，FTP 递归遍历慢需限深）
- **排序**：名称/大小/时间三列可切换升降
- **双击行为**：目录进入；文件 → 预览（可编辑的进编辑器）
- **键盘**：Delete 删除选中、F2 重命名、Ctrl+C/V/X 剪贴板、Ctrl+A 全选、Backspace 上一级
- **空态/错误态**：连接失败给「重试」按钮 + 具体错误（超时/认证失败/路径不存在分类文案）；密钥未配置 → 引导去配置页

## 四、文件查看与编辑（重点）

| 场景 | 行为 |
|---|---|
| 图片（png/jpg/webp/gif/svg） | 弹层预览（localres:// 协议复用，本地下载临时文件后展示）；支持缩放 |
| 文本类（css/js/html/json/yaml/njk/txt/md…） | **内置编辑器**（与 EDM 邮件编辑器同源的代码编辑组件）打开，保存写回远端；超阈值（256KB）只读提示「文件过大，请下载编辑」 |
| 音视频 | 一期不做在线播放（下载后本地打开），列表给「下载」直达 |
| 二进制/未知扩展 | 不提供预览入口，只有下载 |
| 编辑保存冲突 | 保存前重新 stat/list 校验 mtime/etag 未变，变了提示「远端已变化，覆盖/放弃」 |
| 新建文件 | 新建空白文本 → 直接进编辑器（FTP/SFTP/OSS 都可写） |

## 五、传输队列（上传/下载统一）

- 右下角常驻队列抽屉（参考 oss-browser 底部状态区）：每项显示 文件名/方向/进度条/速度/剩余时间/失败原因
- 并发限制：同通道 3 并发（OSS 可 5）；失败自动重试 1 次 + 手动重试；单任务可取消
- 批量上传递归展平目录结构；同名冲突策略默认「覆盖前确认」（可记住本次选择）
- 下载落点：userData/downloads/<通道id>/...（设置里可改），完成后可一键打开所在目录

## 六、安全与门控

- **写操作门控**：删除/重命名/移动/新建/编辑保存/上传，打包版与 dev 一致放行（用户就是管理员），但删除类必须二次确认（输目录名确认的仅递归删大目录）
- **路径安全**：所有操作经 main 侧归一化 + 越权拒绝（不允许越出通道根；`..` 拒绝）
- **密钥零落地**：AK/口令仍走 safeStorage 注入 main，渲染层零接触；诊断报告不含文件系统操作的内容数据
- **审计**：全部写操作记入日志（tool=upload，action/路径/结果，不含内容），error 级别纳入 N2 健康度与诊断报告

## 七、任务拆分（复杂度估算）

| # | 任务 | 复杂度 |
|---|---|---|
| F-1 | shared 契约：FsEntry/FsListQuery/FsOp/传输事件类型 + IPC 通道（fs:list/stat/mkdir/rm/cp/mv/write/read + fs:transfer 事件） | 中 |
| F-2 | main `fs-remote.ts`：FTP/SFTP 浏览驱动（list/mkdir/rm/rename/cp/read/write/stat，basic-ftp/ssh2 复用） | 中高 |

| F-4 | 传输队列引擎：并发/进度/重试/取消/冲突确认（main 侧） | 中高 |

| F-6 | 预览与编辑：图片弹层（localres 复用）+ 文本编辑器 + 阈值 + 冲突检测 + 新建文件 | 中 |
