## 一、U1 dev 新增工具自动感知（P1）

### 背景
工具开发指南 §六：向导创建工具后必须重启 `pnpm dev`（`import.meta.glob` 构建期扫描不支持热加载新目录）——打断开发节奏。

### 方案（分两层，先易后难）

| 层 | 做法 | 说明 |
|---|---|---|
| L1 提示层（先做，低成本） | dev 模式下渲染层定时（或窗口 focus 时）调 `dev:toolScan` 轻通道：主进程 `fs.readdir('tools')` 对比当前 catalog，发现新 id → 顶部横幅「检测到新工具 xxx，点击热载入」 | 不动构建链，零风险；热载入失败自动回退提示「请重启 dev」 |
| L2 渲染层热载入（核心） | 渲染层 `toolComponent` 改为**动态 import()**：`import(\`../../tools/${id}/src/renderer/${Pascal}.vue\`)`——Vite dev 对动态 import 新文件支持即时编译；主进程 main 侧插件加载改 `await import()` 同理 | 风险点：`import.meta.glob` 现用于构建期收集 manifest；需改为 glob（运行时被动）+ 动态 import（按需）双轨；preload 类型不受影响 |
| L3 兜底 | 热载入失败（rolldown/Vite 不识别新路径等）→ 横幅明确提示重启 dev，且 L1 常驻保证「新工具一定可见」 | 不会比现状差 |
