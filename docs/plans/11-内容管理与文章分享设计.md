## 二、数据层设计（NeDB）

项目已有 NeDB 数据层 `@sshk/repository`（@seald-io/nedb，纯 JS 免跨架构 rebuild），新增集合零新增依赖；访问链路照抄 fsAnnotations/fsFavorites（main service 直用 `services.repository`，IPC `content:list/get/save/remove`，handleOk + toPlain，preload + env.d.ts 同步）。

| 项 | 设计 |
|---|---|
| 集合名 | `contents`（BACKUP_COLLECTIONS 成员，随备份 zip 导出；`backup/data/` 映射与 `@sshk/backup` 同步）✅ #9 |
| ID 前缀 | `cnt`（entityId 规约） |
| 文档模型 | `ContentDoc extends BaseEntity { name: string（必填）; html: string（toStoredHtml 存储态）; summary?: string; tags?: string[]; status: ContentStatus; wordCount: number; }` |
| 派生字段 | `wordCount` 保存时由 HTML 提纯文本后走 rich-text `countText()` 算好入库（列表直接展示，不逐行解析 HTML）；`createdAt/updatedAt` 由 BaseEntity 提供（北京时间 ISO 带 +08:00，列表直接显示） |
| 分享票 | **不入库**：分享关系是 ShareHub 路由，实时从 `shareHub.list()` 按 toolId+contentId 反查（对齐海报 #108 的做法），避免双写与失效票残留 |
| 软删除 | 沿用 repository 惯例 `archived:true`；硬删仅二次确认后触发（危险操作铁律） |
| 大小 | wangEditor HTML 几百 KB 级，NeDB 单文档无压力；图片一律外链（图片库 URL）不入库 |
| 已知坑 | 不用带 `.` 的字段键（Poster markCounts 事故教训） |

## 三、UI 设计

### 3-1 入口与多菜单组织
`tool.manifest.json` menus 增加 `{ id: 'contents', label: '内容管理' }`（files 与 profiles 之间）；`FileManagerPage.vue` 注册 `ContentsPage`（入口壳 + `pages/` 子目录，遵守 renderer 顶层唯一 `*Page.vue`）。

### 3-2 列表列（8 列，#1）
| 列 | 内容 |
|---|---|
| 名称 | 文本，超长省略号（注意 CSS 截断只对自身文本生效） |
| 标签 | `el-tag` 多个 |
| 字数 | `wordCount`（库字段直出） |
| 状态 | 状态 tag（见 §五） |
| 创建时间 / 更新时间 | BaseEntity 时间，北京时间字符串 |
| 分享状态 | 未分享=灰色 tag「未分享」；已分享=**复制链接按钮** + 类型 tag（**自己的**=primary、**公用的**=warning）+ 可访问性（可访问=success / 已失效=danger），颜色 + tooltip 标注来源与剩余时间；口径与海报 #108 一致 |
| 操作 | 见 §三-3 |

### 3-3 列操作与顶部操作（#2/#3）
- 列操作 7 项，按项目「常用外置、次要进更多▾」约定分档：**外置** 编辑(primary) / 分享(success) / 复制链接(success) / 删除(danger) / 更多▾；**更多内** 复制（另存为）、导出、导出 HTML、导出 MD。
- 顶部：新建内容(primary) / **分享内容**(success，公用总链接) / 分隔 / 批量删除(danger) / 批量导出 / 批量导出 HTML / 批量导出 MD（warning）。批量项在勾选行后启用，危险项二次确认。
- 语义配色铁律：primary=查看/新建、success=上传/下载/分享、warning=导出/复制/批量、danger=删除。
- 所有会立即失效/覆盖的动作（删除、批量删除、撤销分享、重新生成、覆盖保存）一律 `ElMessageBox.confirm`（禁遮罩禁 ESC）。

### 3-4 复制（另存为，#2）
点「复制」打开同一个编辑弹框、预填当前内容，用户改名后**保存生成新 `cnt` 记录**（不是改原记录）；新记录 `status` 重置为草稿、不继承任何分享票。表单 label 一律 `label-width="auto"`（禁固定 px）。

### 3-5 编辑弹框四态 + 富文本全屏兼容（#4/#8）
- 弹框自绘 header 四控件：最小化 / 最大化 / 全屏 / 关闭，**打开默认最大化**；最小化收为可拖拽悬浮条（复用 TransferPanel `useDraggable` 范式），点击复原。
- 层级共存约定（写死进实现）：内容弹框最大化/全屏是**外层容器**行为；富文本 `fullScreen()` 是 `@sshk/rich-text` 的 Teleport 到 body + `z-index:2147483647`（见共享规划 §七）。富文本全屏时盖住弹框（含其 header），退出富文本全屏后回到弹框最大化态；二者状态互不改写，各自 exit 只清各自 class。
- 图片上传：`onUploadImage` + `@sshk/file-picker` 图片库桥接注入（C2 唯一注入点），文章内图片 URL 一律外链不落库。
- 编辑形态配置：`app.content.editorMode: 'dialog' | 'page'`，默认 `dialog`；dev 下两种模式全量可切（AGENTS.md 开发铁律），配置项仅决定打包版默认表现。接口层把编辑器包成独立组件，`dialog` 与 `page` 两种壳共用同一编辑器，切换只换容器。

## 四、文章分享方案 B + C（#5，核心）

放弃原稿建议的 A（快照导出）。B/C 正好覆盖「自己的 / 公用的」两种语义：

| 方案 | 路由 | 场景 | 链接形态 |
|---|---|---|---|
| **B. 单篇活路由（自己的）** | ShareHub 新增 route kind=`content`，handler 按 contentId 从 NeDB 读 html 出阅读页 | 列操作「分享」、分享状态列「已分享·自己的」 | `http://IP:port/<token>/`，token 绑内容， Always 最新 |
| **C. 目录级公用总链接（公用的）** | 顶部「分享内容」建一条路由指向内容集合，出**文章列表页**（标题/摘要/时间，海报列表前缀范式） | 顶部「分享内容」、一次分享所有内容 | 一条链接浏览全部（**仅展示已发布**，见 §五） |

**优先级（用户 #3 明确）**：复制链接时 **自己的优先** —— 该行若有活着的 B 票就用 B（直达单篇），否则回落到 C 公用总链接 + 该篇锚点/路径。与海报 #102 `copyPosterLink` 的「本行票优先，否则列表前缀+路径」同构。

**B 的实现落点（待确认，见 §九-1）**：不让 share-core 直接依赖 `@sshk/repository`（避免 core→repository 依赖反转，破坏纯静态内核定位）。建议 ShareHub 暴露 `registerContentResolver((contentId) => { title, html } | null)`，宿主注入读库回调；内核命中 content kind 时调 resolver，null 则 404（文章删除/改名后链接不再悬空出旧内容）。TTL / `?ak=` / 撤销 / 续期 / 二维码 / 访问日志全部复用 09 既有能力。

**图片可达性（B/C 通用）**：文章内图片是图片库外链——云/远端域名直链访客可直接加载；若走本地 ShareHub 图片链接，要求访客同局域网且对应路由有效，阅读页加提示文案。

## 五、状态机（#7）

建议三态 + 独立软删除位（待确认，见 §九-2）：

```
draft（草稿） --发布--> published（已发布） --撤回--> draft
                          |
                       下线 --> retracted（已下线，可选）
删除 = archived:true（独立字段，与 status 正交）
```

- 新建/复制 → `draft`；只有 `published` 进入 C 公用列表；B 单篇分享不要求状态（草稿也可临时分享）。
- 状态变更走 `content:save` 的 status 字段，UI 用带确认的下拉/按钮（下线/撤回二次确认，因会令已发链接从列表消失）。

## 六、导出与三件套（#2）

- **导出（三件套）**：打 ZIP 含 `原始内容.html`（`toStoredHtml` 编辑器存储态）、`阅读页.html`（`toDisplayHtml` + 阅读页样式壳）、`内容.md`（`htmlToMarkdown`）；复用 `fflate`（edm-studio 已有依赖）或 `@sshk/backup` 的 zip 能力。
- **导出 HTML**：单文件阅读页 HTML；**导出 MD**：单文件 Markdown（往返不保真，文档已声明）。
- **批量导出**：多选打一个 ZIP，每篇一个子目录放三件套；批量导出 HTML / MD 同理按扩展名汇总。
