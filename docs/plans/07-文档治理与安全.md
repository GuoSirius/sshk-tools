## 七、A-T4 latest 策略升级 SOP（P1）

### 落档：`docs/05-release/依赖升级SOP.md`

```
0. 触发条件：安全漏洞（audit/Dependabot）或功能需要；非必要不主动批量升级
1. 升级前：git status 干净 → 记录当前 lockfile hash
2. 执行：pnpm up --latest（全量）或 pnpm up <pkg>@latest（定点）；Vue2/Vue3 双线库除外（永远钉大版本，见踩坑 #17）
3. 必跑：pnpm verify（13 项 + build + 全部单测）→ pnpm audit --registry=https://registry.npmjs.org
4. 破坏处理：TS 大版本类 breaking → 参照 D24 模式（受控例外写入 check-latest 白名单）；API breaking → 修复 commit 单独提交
5. 提交：pnpm-lock.yaml 变更单独 commit（不与功能混合），message: chore(deps): upgrade ...
6. 记录：台账登记升级条目（版本 from→to + breaking 处理）；重大升级补 CHANGELOG
```
