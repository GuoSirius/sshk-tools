## 五、X5 构建裁剪（Q3 衍生候选，待你拍板）

### 背景
你原以为分发白名单能"构建时只打选中的工具"。实际白名单只控运行时可见性，构建永远全量。若确实想要"按选择打包、缩小安装包"，是新能力：

| 方案 | 做法 | 代价 |
|---|---|---|
| A 白名单裁剪构建（推荐形态） | 打包前读 `app.distribution.includeTools` → 生成裁剪清单 → electron-builder `extraResources`/asar 构建时排除未选工具的 renderer chunk + main 注册 | 中高：electron-vite glob 是构建期定死，需引入两段构建或运行时动态 import 改造；autoUpdater 产物差异管理 |
| B 维持现状 + 文档澄清 | 构建全量，白名单只管可见性（安装后仍可启用被隐藏的工具） | 零成本；安装包体积偏大 |

> 建议：当前 5 个工具全量包体积可控，**先选 B + 把白名单语义在 UI 上讲清**（悬浮说明"仅影响分发可见性，不影响安装包内容"）；等工具数量显著增长或确有保密需求再上 A。
