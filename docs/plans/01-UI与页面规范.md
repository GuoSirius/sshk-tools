## 一、表单规范

### 1.1 label 与布局

| 规则 | 内容 |
|---|---|
| **label 一律 `label-width="auto"`** | EP 在同一 `el-form` 内取全部 label 最大宽度统一右对齐，天然不换行，加字段免调宽度；禁固定 px |
| **禁用 auto 的例外** | `v-show` 切换的表单（MailEditor 步骤）、`el-tab-pane` 隐藏挂载的表单（ToolManifestDialog）——隐藏时测宽为 0 会让 label 塌陷，**保持固定宽度**（如 90px / 130px）且须容下最长 label |
| **el-dialog / v-if 表单** | 可安全用 auto（懒挂载时可见） |

### 1.2 FormGrid 统一栅格

- 统一栅格组件：`@sshk/ui-kit` 的 `FormGrid`（`cols` / `full` 两类插槽；CSS grid `repeat(2, 1fr)` + `grid-column: span 2` 独占行；`column-gap: 8px`）。
- **默认 2 列，宽松 3 列**：同一配置分组内，短表单项（开关、下拉、短输入、数字）默认排 2 列；分组项少且都短时可用 3 列。
- **特殊项独占整行**：长文本 textarea、代码编辑器、路径选择（dir/file，带按钮）、表格/行编辑器、富文本、白名单多选大控件——独占整行；manifest configGroups 字段可加 `full: true` 标记。
- **分组不打散（硬约束）**：明显关联的一组配置（如「自动安装更新」开关+说明、「分发白名单」选择+保存按钮、一对 host/port）必须同组同区，禁止为凑列数拆开；宁可整组独占一行。
- **顺序即语义**：先提炼每项的归属分组与排列顺序（高频/主操作在前，低频/高级在后），再套列布局。
- **响应式降级**：窄窗口（<900px）自动降为单列，分组顺序不变。
- **列内控件统一 `width: 100%`**，由栅格控宽，禁止手写散乱宽度。
- **开关控件文字与开关同排**；行内注释只一两个词。

### 1.3 双层校验铁律

- 前端表单校验 + 后端（IPC/入库前）校验**都要有**。
- 表单校验失败：停留当前页、**不发 IPC**、控件下红字（`color: var(--el-color-danger)`，参照 `ContentEditorCore` 的 tip）。
- 后端业务校验失败：`throw new AppError(msg, 'validation')`（勿裸 `throw new Error` 刷堆栈）。
- 必填项显示红星（`el-form-item` required），保存时空值拦截。

### 1.4 FormHint 与 hint 一句话原则

- 提示文案一律用 `@sshk/ui-kit` 的 `FormHint`，禁散写 `.hint` span（样式已废弃登记）：
  - 默认**上下放置**：独占一行、与输入框精确左对齐；
  - `inline` 左右放置：与控件同排，固定留 12px 边距；
  - `detail`：问号弹出完整说明（长解释一律进 tooltip，勿平铺）。
- **一句话原则**：hint 本体控制在**一行内（≤20 字）**，只说「这是什么/默认是什么」；长解释撤掉或进 `detail`。文案直述、无「需要/请注意」类废话；关键词加粗或 `「」`。
- **FormGrid 内的间距由 `column-gap: 8px` 统一管**：同线提示留 8px 边距，换行后的提示落在行首与输入框精确左对齐。**FormGrid 内的提示不要再手写 margin-left**。

### 1.5 控件尺寸（全局拉平，页面零覆盖）

| 规则 | 说明 |
|---|---|
| **全项目 32px 统一** | `theme.css` 把 EP 的 small 档整体拉平到默认档（`--el-component-size-small: 32px` 等）。**页面级不要再写任何控件高度覆盖** |
| **`size="small"` 语义保留** | 密集表格等场景仍可写（渲染与默认档同高，仅语义标记） |
| **配套拉平** | tag（32px）、分页页码、复选/单选字号已配套对齐 |
| **组内圆角归 EP** | 全局不覆盖 `border-radius`——按钮组/单选组「首尾圆、中间直角」由 EP 组规则控制 |
| **数字框加减钮** | 全局撑满输入框全高、左右对称同底色；`el-input-number` small 档宽 150px |

- 落地方式：全局规则只改 `apps/desktop/src/renderer/styles/theme.css` 与 `packages/ui-kit/src/components/FormGrid.vue` 两处，页面级零散覆盖视为违规。

## 二、列表页规范

> 定版：2026-11-20（用户明确要求，所有列表页通用）；样板：`ListPageShell` + `useTablePage`（RoutesPage/ProxiesPage/LogsPage/ContentsPage 等）。

### 2.1 页面结构顺序（固定）

**筛选栏 → 操作栏 → 表格 → 分页**，四段用 `@sshk/ui-kit` 的 `ListPageShell` 承载（filter / ops / default / footer 四 slot），布局与间距 CSS 已上收 theme.css `.lp-*` 全局类——**页面不再各自维护三段式 scoped CSS**。

### 2.2 筛选栏

- 每个筛选控件前必须有文本 label（`搜索`、`时间`、`标签`、`分享状态`…），**明确告知在筛什么**，不允许只靠 placeholder 传达语义。
- label 统一样式：12px、次要文字色（`var(--el-text-color-secondary)`），与控件同排垂直居中。
- **label+控件必须包进 `.f-item`**（`display:inline-flex; white-space:nowrap`）：筛选栏 flex-wrap 换行时以「一对」为单位换行，禁止 label 与控件错开两行。
- placeholder 只写「全部 / 标题 / 描述」等短词，不重复 label 语义（禁「全部分享状态」「状态码：全部」式写法）。

### 2.3 控件宽度

| 控件类型 | 宽度 |
|---|---|
| 输入框 / 单选下拉 / 多选下拉（默认） | `180px` |
| 时间范围选择器 | `360px` |
| 单个时间选择器（非范围） | `180px` |

- 同一页面内同类控件宽度必须一致；一行放不下允许 flex-wrap 换行，不允许为凑行宽压缩某个控件。

### 2.4 时间范围精确到秒

- 默认 `type="datetimerange"` + `value-format="YYYY-MM-DD HH:mm:ss"` + `:default-time="[00:00:00, 23:59:59]"`。
- 过滤比较用毫秒闭区间，统一走 `@sshk/shared` 的 `inMsRange`，勿散写 `Date.parse` 比较。
- **例外**：业务语义本身就是按日的（用量统计按自然日汇总等），可退化 `daterange` / 日粒度，需代码注释说明例外原因。
- 禁止在筛选层把时间截断到日再交给数据库——用户看到的精度必须与实际过滤精度一致。

### 2.5 查询 / 重置（草稿生效分离）

- 筛选栏末尾固定两个按钮：**查询**（`type="primary"`，回车触发）+ **重置**（default）；禁止「清空筛选」text 按钮。
- **草稿/生效分离**：控件值=草稿态，点查询才拷贝为生效态参与过滤（服务端分页页天然一致）；`useTablePage()` 的 `draft` / `applied` / `search()` / `reset()` 已内置。
- **重置语义**：清空全部筛选控件并**立即生效**（重置即查询一次）。
- 间距：查询/重置互相间距与控件一致（归零 EP 按钮自带 12px 兄弟 margin，走容器 gap）；查询与前方控件之间加大间隔 `margin-left: 16px`（`.lp-filter > .el-button:first-of-type` 已内置）。

### 2.6 操作栏

- 操作按钮（新建/导出/批量删除等）**独占一行居右**（`justify-content: flex-end`），不得与筛选控件混排一行。
- **紧凑口径**：容器 `gap: 4px` 并归零 EP 兄弟 margin（防 gap+12px 双重间距），按钮左右 padding 8px（`.lp-ops` 已内置）。
- 危险/批量操作与普通操作之间可用 `el-divider direction="vertical"` 分组。

### 2.7 分页

- 统一用 `@sshk/ui-kit` 的 `ListPagination`：`layout="total, sizes, prev, pager, next, jumper"` 固定，页尺寸候选 10/20/50/100，**页尺寸变化自动回第一页**（防越界）。
- 分页信息中文化走全局 zh-cn locale（main.ts 已装配），**勿再手写「共 X 条」到分页**；服务端分页总数展示属例外（如 LogsPage 操作栏）。

## 三、留白与间距

> 立项：2026-11-19 用户反馈「内容区直接靠边了，需要留有一定间距。本项目所有页面实现都该如此」。

### 3.1 设计 token（唯一来源：theme.css `:root`）

| token | 值 | 用途 |
|---|---|---|
| `--sshk-page-padding` | `20px` | 页面内容区四周留白（页面根容器 padding） |
| `--sshk-gap-sm` | `8px` | 紧凑间距：工具栏内按钮间、表格/分页与工具栏之间 |
| `--sshk-gap-md` | `12px` | 常规间距：卡片之间、常规区块之间 |
| `--sshk-gap-lg` | `16px` | 宽松间距：大区块、桌面卡片网格 |

调整留白**只改 token**，全项目自动生效；禁止在页面里写死具体 px 覆盖 token。

### 3.2 强制规则

1. **页面根容器必须有 `padding: var(--sshk-page-padding)`**：
   - **ToolPageLayout 豁免条款**：使用 `ToolPageLayout` 的页面由全局 `.tool-page-body { padding: var(--sshk-page-padding) }` 统一提供，**页面自身不要再写 padding**（避免双重）；
   - 不使用 `ToolPageLayout`、自管根容器的页面：根容器必须显式 `padding: var(--sshk-page-padding); box-sizing: border-box`；
   - 桌面落地页 `.desktop` 的 `28px 32px` 是既定特例（大网格），保留；
   - 弹框内部内容由弹框自身内边距提供，不套用本规范，避免双重留白。
2. **页内区块之间必须有间距**：flex/grid 布局用 `gap`；纵向排列的区块（工具栏→表格→分页）用 `gap: var(--sshk-gap-sm)`；卡片网格用 `--sshk-gap-md` / `--sshk-gap-lg`；禁止相邻区块 gap/margin 为 0 视觉粘连。
3. **弹框/浮层里的表单区同样遵守**：标题栏、正文、footer 三段之间留白，正文不得贴弹框边。

### 3.3 ListPageShell flush 条款（P6-1）

页面嵌在已有留白容器（如 `ToolPageLayout` 的 `.tool-page-body`）内时，`<ListPageShell flush>` 去根 padding（`.lp-page--flush { padding: 0 }`），避免「宿主 20px + .lp-page 20px」双重留白。纯工具页（edm/badge/template 壳内）一律 flush；应用管理自管页不 flush。

### 3.4 自检口径

- [ ] 根容器留白 20px（ToolPageLayout 页面除外，由全局提供）？
- [ ] 页内相邻区块有 gap（≥8px）？
- [ ] 没有写死的具体 px 覆盖 token？
- [ ] 表格/分页不贴边、不贴弹框底？

## 四、弹框规范

### 4.1 双禁（危险操作铁律载体）

- 所有 `el-dialog` / `el-drawer` 必须带**字面量**属性 `close-on-click-modal="false"` 与 `close-on-press-escape="false"`（绑定写法 `:close-on-click-modal` 不被 check-dialogs 门禁识别，会挂 CI）。
- `ElMessageBox.confirm` 同样必须 `closeOnClickModal: false` + `closeOnPressEscape: false`（check-dialogs 已补扫）。
- 危险操作（撤销/删除/重新生成/覆盖/清空等）一律二次确认，按钮条件不符直接 return 必须给 toast，禁止静默。

### 4.2 确认弹框分轨（Q-07/C4）

| 轨道 | 场景 | 组件 |
|---|---|---|
| **简单确认** | 删一条/撤一个/纯提示，无需展示清单 | `ElMessageBox.confirm`（双禁选项齐备） |
| **复杂表单确认** | 需展示目标清单/多步后果 | `@sshk/ui-kit` `ConfirmDialog`（targets 列表预览前 5 个 + `danger` 语义色 + confirm/cancel 事件） |

### 4.3 内缩与聚焦

- `.el-dialog` 唯一内缩层 `padding: 12px 16px 0`；body 归零；header `0 0 10px`；footer `12px 0 16px`（全局规则，页面不覆盖）。
- 自动聚焦走 `apps/desktop/src/renderer/focus-on-dialog-open.ts`（`[data-autofocus]`），**勿用 EP 原生 autofocus**（二次打开失效）。
- 所有弹框打开后输入框自动聚焦，不用先点一下。

### 4.4 EP dialog 陷阱与 Teleport

- **afterLeave 回发**：EP 的 use-dialog 会在 afterLeave 回发 `update:modelValue=false`（程序性隐藏也回发）——v-model 绑 computed 时 setter 必须 no-op，关闭入口直调 doClose。
- **Teleport 到 body 的覆盖样式必须放非 scoped 全局块**（`:deep()` 打不进 teleport 后的 DOM）。富文本全屏同理（Teleport + 全局 `.is-fullscreen` 样式）。
- 全屏/最小化四态口径见台账 #129 系列；最小化手柄停靠工具页主体右下角 + ResizeObserver 跟随。

## 五、按钮语义配色与图标

### 5.1 语义色

| 色 | 动作 |
|---|---|
| `primary` | 查看 / 新建（默认主操作锚点） |
| `success` | 上传 / 下载 / 统计 |
| `warning` | 复制 / 移动 / 清理 / 导出 |
| `danger` | 删除 |
| `info` / 无色 | 次要操作、纯文字按钮带色 |

- 常用操作外置工具栏，次要项进「更多▾」。

### 5.2 图标（D50 视觉铁律）

- **图标优先级**：`@element-plus/icons-vue` → FontAwesome（`fa-solid`/`fa-regular` 类名全局可用）→ 自定义 SVG。
- **能用图标处尽量用图标**（按钮/状态/操作列等），美观大方；**禁裸 `↓`/`▾`/`↑` 等 Unicode 箭头**（统一换图标库，如 MoreFilled、Bottom、Top、ArrowDown）。
- 语义色沿用总纲 §2.5 顶栏口径：主题=purple、检查更新=success、验证引导=warning、更多操作=info、应用管理=primary。

## 六、公共组件接线约定

> 公共组件全部在 `@sshk/ui-kit`（分享弹框在 `@sshk/share-core/ui`）。执行总原则：禁止散写 `.hint` span、手写空态、手写分页 CSS、散落 `catch { ElMessage.error }`。

### 6.1 useTablePage() 列表状态

`useTablePage(options)` 统一承载：分页状态 + 加载/错误 + 草稿/生效筛选分离 + 刷新 + 轮询（`pollMs`）+ 内置 useSelection。**接线约定（硬性）**：

1. **el-table 必须绑定 `:row-key="rowKey"` 与 `:data="data"`**；跨页勾选列加 `reserve-selection`（EP 原生支持数据变化时保留勾选）。
2. **批量操作单一真相**：一律读 `selection.count` / `selection.selected`，不读表格瞬时勾选。
3. **prune 时机**：删除/导入覆盖成功回调后调 `selection.prune(validIds)`，防「幽灵计数」。
4. 新页面 `selection: true` 即内置跨页多选，零成本获得（表头全选/半选用 `isPageAllSelected` / `isPageIndeterminate`）。
5. 客户端模式 `clientFilter` 读 `applied`；服务端模式筛选条件放进 fetch 闭包读 `applied`。

### 6.2 TableOpsColumn 操作列

- `@sshk/ui-kit` `TableOpsColumn`：**≤3 个内联按钮**（`actions`，超出自动收进「更多▾」下拉，MoreFilled 图标），`more` 声明始终进下拉的语义化次要项（危险操作收进更多）。
- 事件 `(key, row)`；列宽/fixed 可配；操作列文案语义色按 §五。

### 6.3 表单抽象三件

- `SecretField`：密码 + 查看回显 + 清除三件套（上传通道等密钥输入统一用，密钥读写流走 `host.setToolSecret/getToolSecret`）。
- `ConnectivityField`：测试连接 + 结果展示（Provider/远程通道表单统一用）。
- `SIGN_URL_HINT`（`form-consts.ts`）：签名 URL 说明常量，禁散写同义文案。

### 6.4 useAction().runWithToast

- 动作执行统一走 `useAction()` 的 `runWithToast(action, { success?, errorPrefix? })`：成功 toast 可选；失败统一取 `err.message` 弹错；返回布尔便于决定是否刷新/清勾选。
- **禁止散写 `try/catch { ElMessage.error }`**；禁止静默吞错。

### 6.5 其它

- `ToolPageLayout`：纯工具页壳（页头+侧栏+页体留白）；应用管理页面由 `AppAdminPage` 统一供页头，页内自管留白。
- `FormGrid` / `FormHint` / `ListPageShell` / `ListPagination` / `EmptyState` 用法见 §一/§二/§三/§七。
- 弹框分轨见 §4.2。

## 七、EmptyState 三类空态

禁止手写「暂无数据」纯 div 空态。三类口径：

| 类 | 场景 | 用法 |
|---|---|---|
| **① 列表数据空态** | 表格数据为空 | `@sshk/ui-kit` `EmptyState`（`description` 引导文案 + `actionText` 主行动按钮 + `@action`），与 el-table `v-if`/`v-else` 互斥渲染；如 ContentsPage「还没有内容；新建一篇开始写作…」+「新建内容」 |
| **② EP 标准空态** | 弹框内/非列表容器等 EmptyState 不适配处 | `el-empty`（EP 标准组件，非手写）；如 MailEditor/ContentManagePage 内嵌区域 |
| **③ 特化引导空态** | 业务特化场景（需多段引导/状态图） | 页面手写保留（如 badge GeneratePage「生成后在此预览」两段式），需在提交信息记录判断理由 |

- 空态文案与主行动按钮配对：能一步引导用户摆脱空态的给 `actionText`。
- 列表页空态由 `ListPageShell` default slot 与 el-table 互斥渲染（见 ListPageShell 头注释）。

## 八、逐页验收清单（唯一清单）

新建/重构任何页面时逐条自查：

**表单**
- [ ] label-width="auto"（例外场景固定宽）？短项成 2 列、强关联组不被拆散、特殊项独占整行？
- [ ] 双层校验齐备（前端拦截不发 IPC + 后端 AppError('validation')）？必填红星？
- [ ] hint 一句话（≤20 字），长解释进 FormHint detail？FormGrid 内无手写 margin-left？
- [ ] 窗口缩窄到 900px 以下自动单列不破版？

**列表页**
- [ ] 每个筛选控件有 label？label+控件包 .f-item？placeholder 只写短词？
- [ ] 控件宽 180px / 时间范围 360px 统一？datetimerange 精确到秒、闭区间走 inMsRange（或注明例外）？
- [ ] 筛选栏末尾「查询+重置」？草稿/生效分离、重置立即生效？
- [ ] 操作栏单独一行居右、紧凑口径？顺序=筛选→操作→表格→分页？
- [ ] 分页 layout 固定+中文（ListPagination）？el-table 绑 :row-key+:data？批量操作读 selection 单一真相、prune 时机正确？
- [ ] 页面用 ListPageShell（嵌套留白容器时 flush）？

**留白**
- [ ] 根容器 20px（或 ToolPageLayout/flush 由全局提供）？相邻区块 gap≥8px？无写死 px 覆盖 token？

**弹框**
- [ ] 双禁字面量属性齐备（el-dialog/el-drawer/ElMessageBox.confirm）？危险操作二次确认走分轨？
- [ ] 自动聚焦 [data-autofocus]？内缩口径未覆盖？Teleport 覆盖样式在非 scoped 全局块？

**按钮与图标**
- [ ] 语义色对表（§5.1）？能用图标处用图标、无裸箭头（D50）？

**空态**
- [ ] 空态走三类口径（EmptyState / el-empty / 特化登记），无手写纯 div 空态？
