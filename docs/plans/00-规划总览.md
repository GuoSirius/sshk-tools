## 一、疑问解答速查（用户本轮提问，已核实代码）

| # | 问题 | 结论（已核实代码） | 详见 |
|---|---|---|---|
| Q3 | 分发白名单=构建时只打选中的工具？ | **不是**。构建永远全量打包所有 `tools/*`（electron-vite glob 扫描）；白名单存 `settings.json → app.distribution.includeTools`，仅控制**运行时哪些工具可见/可分发**（主进程 `resolveToolCatalog` 裁决）。「仅开发」标签指这个配置**只在 dev 界面出现**。选中的信息存在 settings.json，与构建产物无关。若你想要"构建裁剪"（只打包选中工具，缩小安装包），是新能力，已列为 **X5 候选** | 05 |
| Q4 | 卡片上「配置」和「编辑」等效？ | **不等效，是"源 vs 覆盖"两层**：①「配置」= 打开 ToolManifestDialog，改的是工具包源文件 `tool.manifest.json`（菜单/配置组/能力/通道/defaults/打包动作），保存后重载目录；②「编辑」= 卡片就地展开表单，写的是 `settings.json → app.toolOverrides.<id>`（显示名/描述/分类/图标/硬依赖），不碰源文件。一个是开发者改源，一个是使用者定制展示。两者有整合空间，方案见 02 | 02 |
| Q5 | 创建工具向导 vs 配置界面能合并？ | **能，且应该合并**。两者本质都是"编辑 manifest 字段"，差异只在：向导从零生成骨架文件 + 分步引导；配置编辑已有 manifest + JSON 预览 + 打包动作。方案：抽取共享表单组件集（基本信息/菜单页面/能力权限/配置项四个区块），两种壳复用同一套表单，仅底部动作按钮不同。你观察到的"默认值差异大"是因向导第 4 步是简化版——合并后统一为编辑器的完整行编辑版 | 02 |
| Q38 | 开发者模式口令双闸是什么？ | 指**打包/安装版**里打开「开发者模式」开关时弹口令输入框（防误开）+ 主进程 `config:set` 二次校验（防绕过 UI 直接调接口开启）。你之前验的"dev/build 界面差异"是另一件事。该项**仍未验证**（需打包版开一次开关） | 总账 A-V4 |
| Q66 | 流式打字没效果？ | 已核实全链路（SSE→主进程逐片 send→渲染逐片 append）**代码是真流式**。"一下子输出"最可能是 Agnes 端点聚合了大分片或网络过快。已列核查项：加 chunk 计数与到达间隔日志定位 | 04 |
| Q74 | 自定义 css = style.css + css 目录？ | **理解完全正确**。版本「样式」tab = `style.css`（内联样式，渲染时最后注入=优先级最高）；其余 css 全部集中在对应层级 `css/` 目录落盘。R24 之后系统与自定义**同为文件域、规则完全一致**。原遗留 F-Q1（css 另存为的"自定义库"目标）大概率已被 R24 顺带解决，列为核实项，核实后直接关闭 | 总账 F-Q1 |
| Q76 | F-T1 / F-T2 什么意思？ | F-T1 = 你已经装过正式包（第 35 条），**顺手看一眼**安装目录 `resources/edm-studio/assets/edm/` 是否存在且有品牌内容（验证 extraResources 生效）；F-T2 = 自定义内容落盘位置：dev 在源码目录旁、打包后在 `userData/custom-edm`，两条路径各写读一次确认不串。都是一分钟级验证，不用专门跑 | 总账 F-T1/T2 |
| Q77 | @shared/@root/@system/@custom 指向哪？ | 见 02-architecture/CSS引用与共享样式规划.md §5.2 对照表。速记：`./css/a.css`=当前版本目录；`@root/css/`=当前来源根（自定义时即 custom-edm）；`@shared/a.css`=**系统根 `css/`**（跨区唯一推荐通道，系统与自定义都能引）；`@system/css/`=显式系统根；`@custom/css/`=显式自定义根；禁止 `..`。写在模板/片段 `.njk` 的 `<link rel="stylesheet" href="...">` 即生效 | CSS 规划 §五 |
| Q58 更正 | csv/xlsx/json 数据源"待补全"？ | **功能已实现**（`pickStats` 支持 xlsx/xls/csv/tsv/json；main 侧 `kindOf` 三类解析齐备），只是你还没用真实文件验。状态改为"待验证"，不需要补开发 | 总账 C-V2 |
